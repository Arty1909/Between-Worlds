# Музыка миров

Двенадцать оригинальных инструментальных тем, сочинённых и синтезированных локально для игры. Без вокала, внешних записей и скачанных сэмплов. Мелодии, гармонии, тембры и стереоэхо заданы в `tools/compose_music.py`. Примерная длительность каждой петли — 50–74 секунды. Хвосты эха переходят через границу цикла; браузер декодирует MP3 и повторяет аудиобуфер.

| Мир | Тема | Звучание |
| --- | --- | --- |
| Комната | Свет в твоём окне | Мягкие клавиши и тёплый фон |
| Изумрудный зал | Изумрудный порог | Приглушённые щипковые переливы |
| Огонь | Тёплое сердце пламени | Низкий пульс и более быстрые арпеджио |
| Лес | Лес, который помнит | Светлые арфовые ноты |
| Река | Песня речной долины | Текущая мелодия и стереоэхо |
| Подземный сад | Розы под землёй | Мягкая минорная тема |
| Звёзды | На полях созвездий | Воздушные колокольчики |
| Лёд | Тишина хрустального дворца | Мягкие низкие клавиши, без стеклянного звона |
| Вечность | Час, который не кончается | Медленные клавиши |
| Архив | Шёпот забытых имён | Тихие низкие гармонии |
| Луна | Отражённый лунный свет | Минорные колокольчики и протяжный фон |
| Между мирами / меню | Между мирами | Главная светлая тема |

Громкость по умолчанию 30%; включение — кнопкой ♫ или M. Настройки запоминаются. Музыка независима от анимации видео. Исходные дорожки видео всегда отключены. Отдельно включаются эффекты мира с собственной громкостью; источник — процедурный синтез в web/effects.js. Переход между темами длится 1,5 секунды. Реплики в одной локации не перезапускают композицию. Скрытая вкладка приостанавливает музыку.

Для повторной сборки нужны NumPy и FFmpeg. Для обычного запуска игры они не нужны — все MP3 уже в этой папке. Параметры и уровни записаны в `manifest.json`.
